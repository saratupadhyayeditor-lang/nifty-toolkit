# nifty-toolkit

A small collection of handy CLI utilities.

## Commands

- `nifty slug "Hello, World!"` — Convert text into a URL-friendly slug
- `nifty words "The quick brown fox"` — Count words, lines, and characters
- `nifty help` — Show help

## Install

```sh
npm install -g .
```

## Test

```sh
npm test
```
